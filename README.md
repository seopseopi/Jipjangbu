# 업무비서

부동산 중개 업무용 엑셀 프로그램을 웹으로 옮긴 개인 업무 관리 사이트입니다. `업무일지(개발필요).xlsb`의 다섯 개 핵심 시트를 기준으로 만들고, 원본 통합문서의 VBA 동작과 삭제된 현황 시트도 함께 분석했습니다.

## 제공 기능

- 오늘 업무와 향후 7일 일정 요약
- 한 번에 최대 10개 물건을 담는 업무 등록·수정·삭제
- 고객 검색, 등록, 수정, 전체 상담 이력
- 매물의 진행/종료 상태 자동 갱신과 변경 이력
- 월별 달력 및 업무구분 필터
- 업무구분과 건물 목록 관리
- Cloudflare D1 영구 데이터베이스

## 개발

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
npm run lint
npm test
```

데이터베이스 스키마를 바꾼 뒤에는 `npm run db:generate`로 마이그레이션을 생성합니다.

## 개인정보 처리

실제 고객·업무·매물 자료는 코드 저장소에 포함하지 않습니다. GitHub 저장소는 비공개이며, 원자료는 비공개 배포의 D1 데이터베이스에만 별도로 이관합니다. 저장소에는 예시 데이터와 재현 가능한 스키마만 둡니다.

분석 결과와 이관 규칙은 [docs/excel-analysis.md](docs/excel-analysis.md)에 정리했습니다.
