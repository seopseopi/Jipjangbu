# 집장부 사용 안내

## 매일의 업무

홈에서 오늘 업무, 앞으로 7일의 예약·예정 업무와 챙겨야 할 일을 확인합니다. 상단의 **큰 글씨**는 현재 기기에만 적용됩니다. 왼쪽 집장부 로고와 각 화면의 홈 버튼으로 돌아올 수 있습니다.

- 전화 상담·방문 예약·매물 등록 버튼으로 업무구분을 미리 선택할 수 있습니다.
- 새 업무에서 고객 이름이나 전화번호 일부를 입력하고 검색 결과를 선택합니다. 없는 고객은 새 고객으로 등록하면 작성 중인 업무에 자동 선택됩니다.
- 업무 수정 창의 ‘이 기록으로 새 업무’는 원본을 바꾸지 않고 오늘 날짜의 새 초안을 만듭니다. 날짜·업무구분·내용을 확인한 뒤 저장하세요.

## 화면을 떠나지 않고 이력 확인

- 업무일지와 홈의 최근 업무에서 **고객 이름**을 누르면 고객 이력, **물건 주소**를 누르면 매물 이력이 열립니다. **일자·내용**을 누르면 업무를 수정합니다. 물건이 여러 개면 ‘외 N건 보기’로 업무를 열어 각각 확인합니다.
- 업무 등록·수정 창의 고객 선택 아래 **고객 이력 보기**, 각 물건의 **매물 이력 보기**를 누르면 같은 창 안에 이력이 펼쳐집니다. 고객·매물 관리 화면으로 이동할 필요가 없습니다.
- ‘저장된 업무 전체 보기’를 누르면 과거 상담 내용과 당시 연결된 모든 물건·가격·출처를 조회합니다. 이 조회는 현재 입력을 바꾸거나 저장하지 않습니다. 현재 수정 중인 업무는 저장된 내용임을 표시합니다.
- 매물 이력은 현재 입력한 물건구분·건물명·동·호수로 찾습니다. 동은 없어도 되지만 물건구분·건물명·호수는 필요합니다. 주소를 바꾸면 기존 이력은 닫히며, 이력이 없는 물건은 빈 목록으로 안내합니다.
- 고객이나 물건이 많아도 이력은 10건씩 더 볼 수 있습니다. 닫기를 누르면 입력하던 업무 그대로 이어갑니다.
- 고객·매물·달력 이력에서 업무를 수정·저장하면 원래 이력이 열린 상태로 갱신됩니다. 업무일지에서 펼쳐 둔 목록 범위도 유지합니다. 삭제나 정렬 기준 변경에 따라 기록의 위치 자체는 달라질 수 있습니다.
- 고객 등록·수정도 입력 중 닫기·Esc·바깥 클릭에 확인을 요청하고, 새로고침에는 이탈 경고를 표시합니다.

## 긴 기록을 편하게 읽기

- 매물 이력은 상태·가격 아래에 원문 메모를 가로 전체 폭으로 표시합니다. **이 매물 확인할 일 추가** 버튼은 메모 아래에 있습니다. 개별 고객·매물 이력도 날짜·상태와 내용을 별도 줄로 보여줍니다.
- 통합검색은 주소·동·호수와 고객 이름을 줄바꿈해 보여줍니다. 긴 업무·고객 메모는 검색어가 나온 부분 주변을 요약하며, 생략한 부분은 `…`로 표시합니다. 결과를 누르면 전체 기록을 볼 수 있습니다.
- 업무 내용 입력창은 최소 6줄이며, 입력한 줄 수에 따라 최대 14줄까지 늘어납니다. 세로 크기는 직접 조절할 수도 있습니다.
- 고객 검색에서 ↑·↓로 고른 항목이 목록 안에 보이도록 자동으로 스크롤합니다. Enter로 선택하고 Esc로 검색 목록을 닫습니다. 고객 이름과 연락처·ID는 별도 줄로 표시합니다.
- 휴대폰의 업무 달력은 날짜순 세로 목록입니다. 주소·고객명은 전체 표시하고 내용은 미리보기로 보여줍니다. **업무 열기**로 전문을 확인하고, 하루 4건을 넘으면 **이 날짜 업무 모두 보기**를 누릅니다. 월·업무구분 필터는 PC와 같습니다.
- 홈·업무 현황의 일정도 주소를 끝까지 보여주며 내용은 여러 줄 미리보기로 확인합니다. 전체 내용은 해당 업무를 눌러 확인하세요. 큰 글씨 설정은 이력·검색·할 일 메모에도 적용됩니다.
- 설정의 건물 분류는 화살표를 눌러 펼치면 건물별 목록으로 확인할 수 있습니다.

## 기존 매물로 업무 작성

새 업무 등록·업무 수정에서 각 물건의 **기존 매물 불러오기**를 누릅니다. 건물명·동·호수로 검색해 선택하면 그 물건의 구분·주소·타입·매매가·전세가·월세가가 입력됩니다. 기본 목록은 진행 중인 매물이며, 종료된 매물도 포함해 찾을 수 있습니다.

- 고객, 업무일, 업무구분, 상담 내용과 다른 물건은 바꾸지 않습니다. 해당 물건에 이미 입력한 값이 있으면 덮어쓰기 전에 확인받습니다.
- 선택 자체는 저장 작업이 아닙니다. 주소와 가격을 검토하고 **업무 저장** 또는 **수정 저장**을 눌러야 반영됩니다.
- 매물의 기존 메모를 새 상담 내용이나 물건 출처로 자동 복사하지 않습니다. 지난 상담이 필요하면 **매물 이력 보기**에서 확인하세요.
- 매물 검색은 입력값을 잠시 기다렸다 조회하며, 결과가 갱신되는 동안 이전 검색 결과를 잘못 선택하지 못하게 합니다. 검색 결과가 1,000건에 도달하면 조건을 좁혀서 찾으세요.

## 다시 연락할 일

홈이나 ‘다시 연락할 일’에서 제목·예정일·메모를 입력합니다. 고객 이력의 ‘다시 연락할 일 추가’, 매물 이력의 ‘이 매물 확인할 일 추가’를 사용하면 관련 고객이나 매물로 바로 이동할 수 있습니다.

- 오늘·기한 지남·앞으로 7일·완료로 모아 봅니다. 날짜는 한국 시간 기준입니다.
- 완료 버튼을 누르면 완료 목록으로 옮겨지며, 완료 목록에서 다시 열 수 있습니다.
- 날짜를 미루거나 수정할 수 있고, 고객·매물 연결만 해제해 할 일 자체는 보존할 수 있습니다.
- 자동 문자·전화·푸시 알림은 전송하지 않습니다. 사이트를 열어 확인하는 업무 목록입니다.

## 확인이 필요한 매물

업무 현황의 오래 갱신되지 않은 매물에서 전체 보기를 누르거나 매물 관리에서 ‘90일 이상 확인 필요’를 선택합니다. 이는 진행 중 매물의 마지막 저장 갱신일 기준이며 실제 매물 유효성을 확정하는 판정은 아닙니다. 이력·원문 메모를 확인하고 필요하면 확인할 일을 등록하세요.

## 목록이 표시되는 순서

업무일지·통합검색·매물 검색에서 `106동 1503호`, `106동1503호`, `106 1503`, `106-1503`처럼 동·호수를 함께 입력할 수 있습니다. 앞에 건물명을 붙여 범위를 좁힐 수도 있습니다. 여러 물건이 연결된 업무는 검색에 맞는 물건을 먼저 보여주며 **검색 일치 물건**으로 표시합니다. 그 주소를 누르면 표시된 물건의 이력이 열립니다. 고객명이나 상담 내용으로만 검색된 업무에는 이 표시가 붙지 않습니다.

업무일지의 새 조건을 조회하는 동안에는 이전 결과와 건수를 숨깁니다. 조회 실패는 0건과 구분하며 **다시 시도**로 같은 조건을 재조회할 수 있습니다. CSV는 현재 조건에 맞는 전체 업무를 저장하되, 물건은 업무당 대표 1건(물건 검색 시 첫 일치 물건)입니다.

- 업무일지: 업무일이 최신인 순서입니다. 같은 날은 최근 수정한 기록부터 표시합니다.
- 홈의 최근 업무: 오늘까지의 기록을 최신순으로 표시합니다. 미래 예약은 예정 일정에서 따로 확인합니다.
- 다시 연락할 일: 기한이 지난 일, 가까운 예정일, 날짜 미정 순서입니다. 같은 기한이면 먼저 등록한 일을 먼저 표시하며 완료 목록은 최근 완료순입니다.
- 고객: 오늘까지 마지막 업무일이 최근인 고객부터 표시합니다. 업무가 없는 고객은 등록일을 사용하며 미래 예약만으로 위에 올라오지 않습니다. 이름순이나 이력 많은 순으로 바꿀 수 있습니다.
- 매물: 기본은 건물명, 동, 호수순입니다. 숫자 동·호수는 2, 10 순으로 비교하며 빈 항목은 뒤에 둡니다. 전체 목록에서는 진행 중인 매물이 먼저 나오고, 최근 등록·최근 변경·오래 미갱신순도 선택할 수 있습니다.
- 확인 필요 매물: 갱신한 지 가장 오래된 매물부터 확인하도록 기본 정렬합니다. 홈·업무 현황·관리 화면은 같은 종류의 목록에 같은 순서를 사용합니다.
- 통합검색: 고객·매물은 정확히 일치하는 항목, 앞부분이 일치하는 항목, 일부 포함 항목 순으로 표시합니다. 업무 검색 결과는 업무일 최신순입니다.

초록색은 선택한 메뉴와 주요 실행 버튼에, 황색은 오늘 확인할 일에, 붉은색은 기한 지남·오류에 사용합니다. 색만으로 구분하지 않도록 상태 문구와 의미에 맞는 아이콘을 함께 표시합니다.

## 중요한 데이터와 백업

고객·업무·매물·할 일은 서버 데이터베이스에 저장됩니다. 새 할 일과 변경사항도 기존의 변경 전후 암호화 백업 대상에 포함됩니다. 변경 전 백업에 실패하면 데이터 변경을 중단합니다.

설정에서 지금 백업을 실행하거나 백업 파일을 내려받을 수 있습니다. 일일 백업은 사이트를 이용할 때 실행되므로 사이트를 열지 않은 날에도 정해진 시각에 실행되는 예약 작업은 아닙니다. 자동 보관 기간은 90일입니다. 중요한 작업 뒤에는 백업 파일을 별도 장치에도 보관하세요.

CSV는 화면별 자료를 옮겨 보는 용도이고, 전체 관계를 복구하는 완전한 백업은 아닙니다. 관리자 로그인 정보는 외부에 공유하지 마세요.
