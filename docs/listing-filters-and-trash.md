# 매물 조회와 휴지통 영구 삭제

2026-09-18

## 매물관리

- 조회 기본값: 전체 상태, 전체 가격, 매물종류 → 이름순.
- 기존 진행 중/종료/90일 필터 대신 저장된 매물 상태(매물등록·매물수정·가계약 등)를 정확히 비교한다.
- 매매가/전세가/월세가 있음은 복수 선택 가능. 선택한 가격 중 하나라도 입력된 매물을 조회한다(OR).
- 상태·매물종류·검색어와 가격 조건은 모두 함께 적용한다(AND).
- 빈 문자열·공백·탭·줄바꿈만 있는 가격은 제외한다. 숫자 범위나 가격 정규화 기능은 아니다.
- 필터 변경 중 이전 조건 결과와 CSV를 노출하지 않으며, 초기화는 가격 선택도 해제한다.
- 업무현황의 90일 미갱신 개별 매물 조회는 유지하며, 제거된 필터로 이동하던 전체보기 링크는 제공하지 않는다.

## 휴지통 영구 삭제

1. 휴지통 행에서 내용을 확인한다.
2. 영구 삭제를 누르고 복구 불가 안내 및 대상 내용을 확인한다.
3. 확인 체크 후 영구 삭제 확정을 누른다. 취소·돌아가기는 데이터 변경이 없다.

선택한 `trash_records` 한 행만 지운다. 현재 업무·매물·고객과 다른 휴지통 항목은 변경하지 않는다.
확인 시 스냅샷의 SHA-256 revision을 전달하며, 변경·복구·중복 요청은 거절한다. DB 삭제도 스냅샷과 삭제 시각을 조건으로 사용한다.
로그인, 동일 출처 검사, 변경 전 안전 백업, 성공 후 백업이 기존 보호 경로로 적용된다. 백업 실패 시 변경하지 않는다.
영구 삭제 후 휴지통에서는 복구할 수 없지만 기존 암호화 백업은 기존 보관 정책대로 유지된다.

검증은 합성 DB의 상태/가격 조합·빈 가격·잘못된 조건, 삭제 확인값·원본 보존·복구 후 삭제 거부, 확인 UI·중복 제출·보안/백업 차단 및 로컬 브라우저 흐름으로 진행한다. 운영 데이터 삭제 테스트는 하지 않는다.
